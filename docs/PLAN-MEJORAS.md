# Plan de mejoras Mi Apiario 3D

1. Entorno 3D más realista, con relieve, vegetación canaria y materiales optimizados.
2. Selección fiable de colmenas, sin selección accidental al arrastrar la cámara.
3. Herramientas para colocar, mover y girar colmenas y otros elementos.
4. Indicadores sanitarios y tareas conectados únicamente a datos confirmados.
5. Controles táctiles y rendimiento móvil.
6. Integración futura con Mi Apiario en solo lectura, con pruebas y recuperación.

## Seguridad de datos
Los datos del prototipo son ficticios. No se permite escribir en el repositorio o almacenamiento de Mi Apiario desde esta aplicación hasta definir y verificar una estrategia de integración segura.
